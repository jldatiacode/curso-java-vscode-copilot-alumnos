# Migración a VS Code y uso de GitHub Copilot para desarrolladores Java

Repositorio de materiales del curso. Los contenidos se irán publicando de forma progresiva a medida que avance la formación.

## Descripción

Curso de 35 horas orientado a desarrolladores Java que migran a Visual Studio Code como entorno principal y quieren incorporar GitHub Copilot a su flujo de trabajo. Se trabaja sobre Windows 11 con WSL2 (Ubuntu), Java 21 y Maven.

## Estructura general del curso

- Módulo 1. Migración a VS Code
- Módulo 2. Control de versiones con Git
- Módulo 3. Desarrollo Java 21 en VS Code
- Módulo 4. Contenedores con Docker
- Módulo 5. GitHub Copilot
- Proyecto integrador

Cada módulo se publicará en su propia carpeta (`modulo-NN-.../`), organizada por temas y apartados. Cada práctica incluye un `README.md` con las instrucciones para ejecutarla.

## Requisitos del entorno

- Windows 11 con WSL2 y Ubuntu
- Java 21 (JDK)
- Maven
- Git
- Visual Studio Code con las extensiones Remote - WSL y Extension Pack for Java
- Docker (a partir del módulo 4)
- Cuenta de GitHub con acceso a GitHub Copilot (módulo 5)
