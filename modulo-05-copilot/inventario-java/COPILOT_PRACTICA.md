# Cómo trabajar con esta plantilla usando GitHub Copilot

1. Descomprime el ZIP y abre exactamente la carpeta que contiene `pom.xml` en VS Code.
2. Verifica Java 21, Maven y GitHub Copilot. Copilot puede requerir inicio de sesión y permisos según licencia.
3. Ejecuta las pruebas ANTES de pedir cambios a Copilot. Los fallos iniciales son intencionados y deben corregirse sin suprimir tests.
4. Utiliza la guía Word de este proyecto: contiene instrucciones de VS Code y prompts orientativos.
5. Para cambios propuestos por Copilot, revisa el diff, acepta solo lo correcto y ejecuta tests/compilación.
6. No publiques código ni datos privados en un repositorio externo: para esta práctica es suficiente el ZIP local.

Copilot puede variar en ubicación de menús, modos y respuesta según la versión, modelo y permisos. Usa los equivalentes disponibles en tu instalación.
