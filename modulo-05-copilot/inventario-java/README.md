# Inventario Java 21 + Maven — plantilla de partida

Abrir esta carpeta con **File > Open Folder** en VS Code.
Requisitos: JDK 21, Maven 3.9 o superior y Extension Pack for Java.
La plantilla inicial compila y ejecuta, pero los cálculos son marcadores de posición.
De las cuatro pruebas JUnit, **tres fallan intencionadamente** hasta completar el ejercicio.
No añadir dependencias a mano fuera de `pom.xml`.
